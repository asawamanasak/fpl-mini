STAGE 01 • INGESTION Dual-Cadence & Auto-Picks

1. Dual-Cadence Pipeline & Auto-Picks

  • Smart Dual-Cadence Orchestration: รันบน GitHub Actions (Ubuntu Latest / Python 3.11) แบบปัก SHA ความปลอดภัย พร้อม 58s Stagger Offset — วันแข่ง ศุกร์–จันทร์ ซิงก์ทุก 1 ชม. และอังคาร–พฤหัส ทุก 4 ชม. ลดโหลดระบบลง ~83% พร้อมปุ่ม Manual Dispatch
  • Dual-Scale & Tier 2 Auto-Picks Live: ลีกมาตรฐาน (Tier 1) ซิงก์คู่ขนานด้วย ThreadPoolExecutor (5 workers + 0.12s Rate Pacer) พร้อมแคช GW สำเร็จรูป (>95%) ขณะที่ Tier 2 (รองรับสูงสุด 3,000 ทีม / 8 workers) ซิงก์ Picks ครั้งเดียวหลังเดดไลน์ลง data/leagues/{id}/gw{gw}.json แสดงแต้มสด กัปตัน แต้มลบ ชิป และสำรองอัตโนมัติครบถ้วน
  • Hybrid xP + FDR Transfer Advisor v2: โมเดลคาดการณ์แต้ม 1–3 GW ในตัว sync_live_fpl.py ผสาน ep_next, ฟอร์ม, xGI/90, นาทีลงสนาม และความยากโปรแกรม FDR ล่วงหน้า 3 นัด (เสริมสัญญาณ Azure xP แบบ Optional Blend)
STAGE 02 • STATE MACHINE Atomic & Zero-Churn

2. Data Integrity & Atomic State Machine

  • POSIX Atomic Replacement: บันทึก multi_fpl_data.json, ไฟล์แยกรายลีก และ Chunks ด้วย tempfile + os.replace ขจัดไฟล์เสียและข้ามการเขียนไฟล์ซ้ำถ้าข้อมูลไม่เปลี่ยน
  • Pre-Commit Validation: ตรวจสอบความถูกต้องของแต้มสด, Auto-Sub, รองกัปตัน (VC x2), ชิปพิเศษ, แต้มลบย้ายตัว (Hits), สกุลเงินรางวัล (THB/USD) และ Tie-Pooling ก่อนบันทึกลงดิสก์
  • Zero-Churn Smart Commit & 6h Heartbeat: ตรวจ Semantic Diff ข้าม Commit เมื่อคะแนน/อันดับไม่เปลี่ยน (Zero Git Bloat) พร้อม Heartbeat Sync ทุก 6 ชม. และรองรับโหมดซิงก์รายลีก (--league <id>)
STAGE 03 • JAMSTACK Shared Bundle & Isolation

3. Config-Driven Jamstack & Multi-Tenant

  • Multi-Tenant Isolation & Season Rollover: ขับเคลื่อนด้วย config/leagues_config.json แยกกลุ่มลีกสาธารณะกับลีกลูกค้าส่วนตัว (noindex + Sitemap Filter) พร้อมเก็บกวาดโฟลเดอร์เก่าอัตโนมัติ
  • Shared Bundle & Decoupled Chunks: คอมไพล์เลอร์ update_preview.py แยก JS กลาง assets/dashboard-app.js ติด SHA-256 Hash Busting, สร้าง /{id}/index.html, data/leagues/{id}.json และ Tier 2 gw{gw}.json ลดขนาด Initial HTML ลงกว่า 85%
  • Hybrid Edge CDN Routing: ให้บริการผ่าน www.fplsawadika.com (Cloudflare DNS CNAME Flattening + Fastly Edge CDN, HTTP/2, Brotli, TTFB < 50ms) เชื่อมต่อกับ Edge API ที่ api.fplsawadika.com
STAGE 04 • CLIENT & EDGE 15s Edge • 20s/90s Poll

4. Adaptive Client Runtime & Edge D1/KV

  • Adaptive Poll, Edge D1/KV & Tier 2 Relay: เบราว์เซอร์ดึงคะแนนและโบนัส BPS สดทุก 20s ช่วงกำลังเตะ (ผ่อนเป็น 90s เมื่อพัก) ผ่าน Cloudflare Workers (Edge TTL 15s/120s/300s), ดึงผัง Tier 2 ผ่าน /picks & /standings พร้อม First-Party Edge Analytics บน D1 & KV
  • Provisional Auto-Subs & Race Guard: คำนวณตัวสำรองชั่วคราวสดระหว่างเกม, โหลด JSON รายลีกแบบ Lazy On-Demand พร้อมป้องกัน Race Condition และซิงก์สถานะด้วย History API + localStorage
  • Zero-Framework, SRI Security & A11y: Vanilla ES6+ Shared Bundle ปักเวอร์ชัน + Subresource Integrity (sha384 บน Tailwind CSS v4.3.5 และ Lazy SheetJS), Edge Security Headers (CSP/HSTS), tabular-nums (CLS: 0.00) และ Page Visibility API

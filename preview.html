Dev Corner & สถาปัตยกรรมระบบ

✓ OFFICIAL SETTLED • แคชระดับ Edge v2.4 Jamstack Fastly + Cloudflare Edge
01

คะแนนสด & เปลี่ยนตัวอัตโนมัติ

  • • อัปเดตคะแนนสดทุก 30 วินาทีพร้อมแต้มโบนัสตลอด 90 นาที ไม่ต้องรอข้ามคืน
  • • เปลี่ยนสำรองและดันรองกัปตัน (VC x2) ให้อัตโนมัติเมื่อตัวจริงไม่ได้ลงแข่ง
  • • บทวิเคราะห์ไฮไลท์สด เกาะติดการสลับอันดับและโมเมนตัมแบบเรียลไทม์
02

ส่องแผนจัดทัพ 11 ตัวจริง

  • • คลิกที่ชื่อทีมเพื่อน เพื่อเปิดดูแผนผังสนามหญ้าและ 4 ตัวสำรอง
  • • แสดงคะแนนรายคน สถานะลงสนาม และนาทีที่ลงเล่นแบบเรียลไทม์
  • • ตรวจเช็กการใช้ชิปพิเศษอย่างชัดเจน (TC, BB, FH, WC)
03

วิเคราะห์การย้ายตัว & ขุมกำลัง

  • • สรุปทุกดีลซื้อขายนักเตะเข้า-ออกของคู่แข่งในลีก พร้อมแต้มลบย้ายตัว
  • • คำนวณแต้มได้-เสียสุทธิจากการย้ายตัวในแต่ละสัปดาห์
  • • วิเคราะห์นักเตะมหาชน (> 70%), นักเตะทีเด็ด (< 20%) และคำแนะนำการย้ายตัว
04

ติดตามสถานะชิปของคู่แข่ง

  • • ตารางแมทริกซ์เช็กสถานะชิปพิเศษ (WC, FH, BB, TC) ของผู้จัดการทีมทุกคน
  • • ตรวจสอบชิปที่ใช้ไปแล้วในแต่ละสัปดาห์ และชิปที่ยังเหลืออยู่แบบแยกเดี่ยว
  • • ไฮไลท์พิเศษแจ้งเตือนชิปที่กำลังเปิดใช้งานระหว่างสัปดาห์แข่งขันสด
05

เงินรางวัล & บัญชีกองกลาง

  • • คำนวณแชมป์สัปดาห์, แชมป์เดือน, สิ้นฤดูกาล และค่าปรับอัตโนมัติ
  • • หักแต้มย้ายทีมในตัว พร้อมเฉลี่ยเงินรางวัลอย่างยุติธรรม (Tie-Pooling)
  • • รองรับมินิเกมเฉพาะลีก เช่น ทายผลบอล และท้าชนคะแนนแฟนตาซี
06

เรดาร์ฟอร์ม & ทำเนียบแชมป์

STAGE 01 • INGESTION ThreadPool & Chunks

1. Pipeline & Multi-Threading Engine

  • Serverless Orchestration: ประมวลผลผ่าน GitHub Actions Runner (Ubuntu Latest / Python 3.11) ตามตาราง Cron ทุก 15 นาที และ Manual Dispatch
  • Hybrid Concurrency & Incremental Cache: ใช้สถาปัตยกรรม 2 ระดับ (Dual-Scale Pipeline) โดยมินิลีกมาตรฐาน (Tier 1: 8 ลีก 146 ทีม 163 รายการ) ซิงก์ควบคู่กันด้วย ThreadPoolExecutor พร้อมแคช GW สำเร็จรูปเพื่อลดการยิง API ซ้ำกว่า 95% ขณะที่มินิลีกระดับคอมมูนิตี้ (Tier 2: 1 ลีก 1,780 ทีม) ใช้โหมด Standings Only เพื่อขจัดปัญหา Rate Limit
  • Azure Transfer AI & Security: เชื่อมต่อ Azure Functions วิเคราะห์แผนย้ายตัวด้วย Environment Secret (AZURE_TRANSFER_FUNCTION_KEY) พร้อมระบบ Fallback อัตโนมัติ
STAGE 02 • STATE MACHINE Atomic Store

2. Data Integrity & Atomic State Machine

  • POSIX Atomic Replacement: บันทึก multi_fpl_data.json, ไฟล์แยกรายลีก และ Chunks ด้วย tempfile + os.replace ขจัดปัญหา Race Conditions หรือไฟล์ JSON เสียหาย
  • Pre-Commit Validation: ตรวจสอบความถูกต้องของแต้มสด, Auto-Sub, รองกัปตัน (VC x2), ชิปพิเศษ, แต้มลบย้ายตัว (Hits) และสูตรเฉลี่ยเงินรางวัล (Tie-Pooling) ก่อนบันทึกลงดิสก์
  • Zero-Churn Smart Commit: ตรวจสอบ Semantic Diff ของคะแนนและอันดับ หากข้อมูลไม่เปลี่ยนแปลงจะข้าม Git Commit เพื่อลดขยะใน Git History (Zero Git Bloat) พร้อม Heartbeat Sync ทุก 6 ชั่วโมง
STAGE 03 • JAMSTACK Edge Compiler

3. Config-Driven Jamstack & Edge CDN

  • Zero-Code Season Rollover: ขับเคลื่อนด้วย config/leagues_config.json 100% สำหรับฤดูกาล 2026/27 รองรับการเปลี่ยนลีกและทีมข้ามฤดูกาลพร้อม Auto-Cleanup ลบโฟลเดอร์ลีกเก่าอัตโนมัติ
  • Decoupled JSON Split & Tier 2 Chunking: คอมไพล์เลอร์ update_preview.py แยกไฟล์ data/leagues/{id}.json และสร้าง Route ประจำลีก (/{id}/index.html) พร้อมแบ่ง Chunks รายสัปดาห์ (data/leagues/{id}/gw{gw}.json) สำหรับ Tier 2 ลดขนาด Initial HTML ลงกว่า 85%
  • Custom Domain & Edge CDN: ให้บริการผ่านโดเมนหลัก www.fplsawadika.com บนระบบ Cloudflare DNS (CNAME Flattening) ควบคู่กับ Fastly Edge CDN รองรับ HTTP/2, Brotli และส่งมอบข้อมูลด้วย TTFB ต่ำกว่า 50ms
STAGE 04 • CLIENT RUNTIME 15s Live Relay & Picks

4. Client Runtime & 15s Real-Time Relay

  • 15s Cloudflare Edge Live Poll & On-Demand Picks: ระหว่างมีแมตช์เตะ เบราว์เซอร์ดึงแต้มสดและโบนัส BPS เรียลไทม์ผ่าน Cloudflare Worker (fpl-live-relay / api.fplsawadika.com) ทุก 15 วินาที พร้อมดึงผัง 11 ตัวจริงของ Tier 2 แบบ On-Demand ผ่านเอนด์พอยต์ /picks
  • Lazy League Switch & Race Guard: โหลด JSON รายลีกแบบ On-Demand เมื่อสลับลีก พร้อมระบบป้องกัน Race Condition และซิงก์สถานะผ่าน HTML5 History API + localStorage
  • Zero-Framework 60 FPS & A11y: พัฒนาด้วย Vanilla ES6+ (0kb Framework) ใช้ tabular-nums (CLS: 0.00), Page Visibility API ประหยัดแบตเตอรี่ และรองรับ Keyboard Focus Accessibility
